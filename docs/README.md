# Pure Promemoria Aziendale — versione web

Per pubblicare questa versione: repository Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main /docs → Save.

Funzioni disponibili nel browser: salvare fasce orarie e coordinate GPS del magazzino; confermare manualmente le timbrature; aggiungere/eliminare/confermare promemoria; registro locale; esportazione e importazione dei dati; prova avviso sonoro; installazione PWA dalla schermata Home.

**Limiti:** non è un'app nativa. Suonerie, controlli orari e GPS richiedono la pagina aperta e attiva. Non usa push, geofencing in background, sincronizzazione cloud o timbratura reale. I dati sono salvati nel localStorage del dispositivo, non sul server.

Per aggiornare: modificare i file in docs, poi ricaricare la pagina. Per l'installazione su iPhone, aprire in Safari e selezionare Condividi → Aggiungi alla schermata Home.
